# Дополнительные сценарии магазина

Открой /static/scenarios.html в локальном магазине.

## 01. Диапазон цен

Действия: Укажи одинаковую минимальную и максимальную цену существующего товара.

Ожидаемый результат: Остаются только товары с этой ценой; границы включены.

## 02. Ошибка диапазона

Действия: Укажи цену от 5000 и цену до 1000.

Ожидаемый результат: Появилась ошибка; оба поля отмечены aria-invalid=true.

## 03. Только в наличии

Действия: Включи фильтр наличия.

Ожидаемый результат: Нет товаров с нулевым остатком. После отключения они возвращаются.

## 04. Комбинация фильтров

Действия: Выбери категорию, диапазон цен и наличие.

Ожидаемый результат: Каждый показанный товар соответствует всем трём условиям.

## 05. Пагинация

Действия: Выбери 3 товара на странице, перейди вперёд и назад.

Ожидаемый результат: Не больше 3 карточек; номер страницы меняется; на первой странице Назад недоступна.

## 06. Сброс фильтров

Действия: Задай поиск и фильтры, затем нажми Сбросить фильтры.

Ожидаемый результат: Поля очищены, выбраны все товары, отображается первая страница.

## 07. Карточка товара

Действия: Открой Подробнее, закрой кнопкой; открой снова и нажми Escape.

Ожидаемый результат: Название, цена и картинка совпадают с карточкой; оба способа закрывают окно.

## 08. Избранное

Действия: Войди, добавь товар в избранное, включи Только избранное.

Ожидаемый результат: Товар виден. Удали его из избранного — он исчезает из выдачи.

## 09. Количество

Действия: В корзине измени количество на 2, затем на 1.

Ожидаемый результат: Сумма пересчитывается; значение сохраняется после перезагрузки.

## 10. Ошибочное количество

Действия: Попробуй 0, -1, 100 или число выше остатка.

Ожидаемый результат: Сервер отклоняет запрос, корзина возвращается к сохранённому количеству.

## 11. Недоступный товар

Действия: Найди товар Нет в наличии.

Ожидаемый результат: Кнопка В корзину отключена; товар можно открыть для просмотра.

## 12. Промокод

Действия: Примени SAVE10, затем очисти поле и примени снова.

Ожидаемый результат: Сначала скидка 10%, затем исходная сумма. Неверный код скидку не даёт.

## 13. Адрес доставки

Действия: Проверь пустой адрес, пробелы, 4, 5, 300 и 301 символ.

Ожидаемый результат: Допустимо 5–300 символов, не только пробелы. При ошибке заказ не создаётся.

## 14. Имя профиля

Действия: Сохрани имя; проверь пустое, пробелы, 1, 100 и 101 символ.

Ожидаемый результат: Допустимо 1–100 символов, не только пробелы. Сохранённое имя видно после обновления.

## 15. Подтверждение отмены

Действия: Создай заказ, нажми Отменить заказ и Оставить заказ. Затем подтверди отмену.

Ожидаемый результат: В первом случае статус new сохраняется, во втором становится cancelled.

## 16. Фильтр заказов

Действия: Создай и отмени заказ, выбери статус Отменён.

Ожидаемый результат: Видны только cancelled. При отсутствии совпадений показано пустое состояние.

## 17. Показ пароля

Действия: Введи пароль и переключи Показать пароль.

Ожидаемый результат: Значение сохранено; тип поля меняется password → text → password.

## 18. Доступ гостя

Действия: Выйди и открой Корзина, Заказы, Профиль.

Ожидаемый результат: Показано Требуется вход; закрытые разделы не открываются.

## 19. Асинхронная оплата

Действия: Создай заказ, нажми Оплатить и обновляй список заказов.

Ожидаемый результат: Статус меняется после обработки события; в тесте используй ожидание состояния.

## 20. API и хранение

Действия: Повтори сценарий через HTTP, затем сверь данные в PostgreSQL и Redis.

Ожидаемый результат: Проверь HTTP-код, тело ответа и сохранённое состояние. Используй отдельные данные для каждого теста.
