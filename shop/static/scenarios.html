20 заданий для автотестов

Выбери сценарий, выполни его руками, затем напиши автотест. По десять готовых E2E лежат в academy/js-wdio/tests, academy/ts-playwright/tests и academy/python-playwright/tests; эти задания расширяют практику.

Один E2E — один файл. Подготовка — pre, одно действие — it, одна проверка с одним expect — check. В TS шаги оформлены через test.step, в Python — allure.step с одним expect или assert на проверку. Селекторы и повторяющиеся действия — в Page Object. Для всех разделов есть готовые методы; справочник — academy/docs/PAGE-OBJECTS.md. В JS проверяй shop.identity(), в TS — shop.identity, в Python — shop.identity. Пользователя и товар создавай через API; после сценария удаляй свои данные.

№СценарийЧто сделатьЧто проверить
01Диапазон ценУкажи одинаковую минимальную и максимальную цену существующего товара.Остаются только товары с этой ценой; границы включены.
02Ошибка диапазонаУкажи цену от 5000 и цену до 1000.Появилась ошибка; оба поля отмечены aria-invalid=true.
03Только в наличииВключи фильтр наличия.Нет товаров с нулевым остатком. После отключения они возвращаются.
04Комбинация фильтровВыбери категорию, диапазон цен и наличие.Каждый показанный товар соответствует всем трём условиям.
05ПагинацияВыбери 3 товара на странице, перейди вперёд и назад.Не больше 3 карточек; номер страницы меняется; на первой странице Назад недоступна.
06Сброс фильтровЗадай поиск и фильтры, затем нажми Сбросить фильтры.Поля очищены, выбраны все товары, отображается первая страница.
07Карточка товараОткрой Подробнее, закрой кнопкой; открой снова и нажми Escape.Название, цена и картинка совпадают с карточкой; оба способа закрывают окно.
08ИзбранноеВойди, добавь товар в избранное, включи Только избранное.Товар виден. Удали его из избранного — он исчезает из выдачи.
09КоличествоВ корзине измени количество на 2, затем на 1.Сумма пересчитывается; значение сохраняется после перезагрузки.
10Ошибочное количествоПопробуй 0, -1, 100 или число выше остатка.Сервер отклоняет запрос, корзина возвращается к сохранённому количеству.
11Недоступный товарНайди товар Нет в наличии.Кнопка В корзину отключена; товар можно открыть для просмотра.
12ПромокодПримени SAVE10, затем очисти поле и примени снова.Сначала скидка 10%, затем исходная сумма. Неверный код скидку не даёт.
13Адрес доставкиПроверь пустой адрес, пробелы, 4, 5, 300 и 301 символ.Допустимо 5–300 символов, не только пробелы. При ошибке заказ не создаётся.
14Имя профиляСохрани имя; проверь пустое, пробелы, 1, 100 и 101 символ.Допустимо 1–100 символов, не только пробелы. Сохранённое имя видно после обновления.
15Подтверждение отменыСоздай заказ, нажми Отменить заказ и Оставить заказ. Затем подтверди отмену.В первом случае статус new сохраняется, во втором становится cancelled.
16Фильтр заказовСоздай и отмени заказ, выбери статус Отменён.Видны только cancelled. При отсутствии совпадений показано пустое состояние.
17Показ пароляВведи пароль и переключи Показать пароль.Значение сохранено; тип поля меняется password → text → password.
18Доступ гостяВыйди и открой Корзина, Заказы, Профиль.Показано Требуется вход; закрытые разделы не открываются.
19Асинхронная оплатаСоздай заказ, нажми Оплатить и обновляй список заказов.Статус меняется после обработки события; в тесте используй ожидание состояния.
20API и хранениеПовтори сценарий через HTTP, затем сверь данные в PostgreSQL и Redis.Проверь HTTP-код, тело ответа и сохранённое состояние. Используй отдельные данные для каждого теста.
